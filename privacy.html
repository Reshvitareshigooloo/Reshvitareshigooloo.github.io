Privacy Policy - Jarvis Clips

Last updated: November 15, 2026

Jarvis Clips is a private tool. Its only user is its owner, Reshad Khalili, who uses it to upload videos to YouTube channels he owns.

What data it uses

With the owner's permission through Google sign-in, it uses the YouTube Data API to upload videos and set their titles and descriptions on the owner's own channels. It does not access anyone else's account.

Storage and sharing

The sign-in token is stored privately on the owner's own server and is used only to upload the owner's videos. No personal data is sold, shared or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used; see the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

Removing access

Access can be removed at any time at https://myaccount.google.com/permissions.
